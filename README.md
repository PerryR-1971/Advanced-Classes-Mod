# Advanced Classes Mod

**Advanced Classes Mod 1.12** for *Heroes of Might and Magic III: ERA 3* expands hero development with new classes, advanced skill progression, commanders, artifacts, spells, warmachines and extensive gameplay options.

Created by **PerryR**, with important contributions by **AlfWithCake** and **anti-victor**.

## Quick start

1. Install the mod through the ERA Mod Manager and enable it.
2. Start a new map or load a compatible savegame.
3. Open the hero-class window by right-clicking a hero portrait.
4. Choose a main class and develop it through secondary skills, levels and class requirements.
5. Use the in-game help and the documentation folder whenever you want to explore a system in more detail.

## What the mod adds

- Three main hero classes: **Warrior**, **Mage** and **Adventurer**.
- Three hybrid classes: **Battlemage**, **Hunter** and **Druid**.
- Master and Grandmaster class ranks.
- Reworked hero specialties, primary-skill growth and secondary-skill chances.
- The Magic Strength system and many new or reworked spells.
- Commanders, including special commanders and unique abilities.
- Upgrades and new functionality for war machines.
- Artifact sets, new adventure objects and additional gameplay systems.
- Optional difficulty, class and balance settings.

## Essential controls

| Control | Function |
| --- | --- |
| Right-click hero portrait | Open the hero-class overview |
| `W` | Open the warmachine window |
| `E` | Open the spellbook enhancement window |
| `A` | Open the artifact inventory |
| `R` | Open the resource overview |

The exact availability of a window can depend on the selected hero, class, skills and current game state.

## Important information

- The mod is designed for **ERA 3**.
- Most options can be configured in the in-game settings, including class-related systems and difficulty features.
- Several systems are intentionally optional. You can keep the mod close to classic Heroes III or enable more extensive mechanics.
- For the best experience, begin a new game after changing major gameplay options.

## Compatibility

Advanced Classes Mod changes core hero-development systems. Before adding it to a large mod setup, check the compatibility notes in the full manual and avoid combining it with mods that replace the same class, commander or primary-skill mechanics.

The mod includes compatibility notes for several common ERA components. Load order can matter; follow the instructions shown in the ERA Mod Manager and the full documentation.
